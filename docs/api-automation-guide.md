# Руководство по использованию сабагента API Automation Specialist

## 📋 Обзор

Сабагент `api-automation-specialist` специализируется на автоматизации последовательных API вызовов с отслеживанием асинхронных задач для проекта InvestmentDataLoaderService.

## 🎯 Как использовать сабагента

### Способ 1: Прямое упоминание в запросе

Просто упомяните сабагента в вашем запросе:

```
Используй api-automation-specialist для создания скрипта автоматизации 
загрузки дневных свечей за весь 2025 год
```

### Способ 2: Использование символа @

```
@api-automation-specialist Создай Python скрипт для автоматической загрузки 
данных за период с проверкой статуса задач
```

### Способ 3: Автоматическое делегирование

Cursor может автоматически использовать сабагента, если задача соответствует его описанию. Например:

```
Нужно автоматизировать загрузку данных за весь год с отслеживанием статуса задач
```

## 📁 Где хранить Python скрипты

**Рекомендуемое расположение:** `scripts/` (корневая папка проекта)

```
InvestmentDataLoaderService/
├── scripts/
│   ├── load-daily-candles-2025.py  ← Python скрипты здесь
│   ├── run-test.bat
│   ├── run-prod.bat
│   └── ...
├── src/
└── ...
```

### Почему `scripts/`?

1. ✅ Уже существует в проекте
2. ✅ Содержит другие скрипты запуска
3. ✅ Логично хранить все скрипты в одном месте
4. ✅ Легко найти и использовать

## 🚀 Использование готового скрипта

### Установка зависимостей

```bash
pip install requests
```

### Запуск скрипта

```bash
# Из корневой папки проекта
python scripts/load-daily-candles-2025.py --test

# Или с полным путем
python C:\Users\ThinkBook\Desktop\Сервисы инвестиций\InvestmentDataLoaderService\scripts\load-daily-candles-2025.py --test
```

### Параметры запуска

```bash
# Тестовое окружение (порт 8087)
python scripts/load-daily-candles-2025.py --test

# Продакшн окружение (порт 8083)
python scripts/load-daily-candles-2025.py

# С исключением выходных дней
python scripts/load-daily-candles-2025.py --exclude-weekends

# Кастомный URL
python scripts/load-daily-candles-2025.py --base-url http://localhost:8083

# Настройка интервала проверки статуса (по умолчанию 3 секунды)
python scripts/load-daily-candles-2025.py --poll-interval 5

# Настройка таймаута (по умолчанию 300 секунд)
python scripts/load-daily-candles-2025.py --timeout 600

# Другой год
python scripts/load-daily-candles-2025.py --year 2024

# Комбинация параметров
python scripts/load-daily-candles-2025.py --test --exclude-weekends --poll-interval 5 --timeout 600
```

## 🔧 Что делает сабагент

Сабагент `api-automation-specialist` помогает:

1. ✅ **Создавать Python скрипты** для автоматизации API вызовов
2. ✅ **Обрабатывать асинхронные задачи** с отслеживанием taskId
3. ✅ **Генерировать последовательности дат** для пакетной обработки
4. ✅ **Мониторить статус задач** через polling
5. ✅ **Обрабатывать ошибки** и повторные попытки
6. ✅ **Генерировать отчеты** о выполнении операций

## 📊 Структура скрипта

Типичный скрипт, созданный сабагентом, включает:

- **Класс загрузчика** - основная логика работы с API
- **Генерация дат** - создание списка дат для обработки
- **Запуск задач** - вызов POST эндпоинтов
- **Мониторинг статуса** - проверка завершения через GET /api/status/{taskId}
- **Обработка ошибок** - retry логика и обработка исключений
- **Отчетность** - итоговая статистика выполнения

## ⚙️ Конфигурация

### Переменные окружения (опционально)

Можно создать файл `.env` в корне проекта:

```env
API_BASE_URL=http://localhost:8083
API_TEST_URL=http://localhost:8087
POLL_INTERVAL=3
TASK_TIMEOUT=300
```

### Параметры командной строки

Все параметры можно передать через аргументы командной строки (см. раздел "Параметры запуска" выше).

## 💡 Советы

1. **Начните с тестового окружения** - используйте `--test` для проверки
2. **Исключайте выходные** - используйте `--exclude-weekends` для торговых дней
3. **Мониторьте прогресс** - скрипт выводит подробную информацию о ходе выполнения
4. **Проверяйте отчеты** - в конце выводится итоговая статистика
5. **Используйте таймауты** - настройте `--timeout` в зависимости от нагрузки

## 🔄 Обновление скриптов

Если нужно обновить скрипт:

```
@api-automation-specialist Обнови скрипт load-daily-candles-2025.py, 
добавив поддержку параллельной загрузки нескольких дат одновременно
```

Сабагент поможет модифицировать существующий скрипт с учетом новых требований.
