# Investment Data Loader Service — Документация

Сервис для загрузки и агрегации инвестиционных данных (акции, фьючерсы, индикативы, рыночные данные) с использованием Tinkoff Invest API и PostgreSQL.

## 🔧 Основные возможности

### Работа с инструментами
- ✅ Загрузка справочников (акции, фьючерсы, индикативы) из Tinkoff Invest API
- ✅ Сохранение в БД с защитой от дубликатов
- ✅ Фильтрация по различным параметрам (статус, биржа, валюта, тикер, FIGI)
- ✅ Поиск по FIGI или тикеру
- ✅ Получение статистики по количеству инструментов
- ✅ Автоматический прогрев кэша при запуске приложения (00:45 МСК)
- ✅ Ручное управление кэшем через REST API
- ✅ Асинхронное сохранение инструментов с параллельной обработкой

### Рыночные данные
- ✅ Загрузка минутных и дневных свечей (акции, фьючерсы, индикативы)
- ✅ Загрузка цен закрытия/открытия основной сессии
- ✅ Цены утренней сессии (с поддержкой выходных и рабочих дней)
- ✅ Цены закрытия вечерней сессии
- ✅ Исторические обезличенные сделки (last trades)
- ✅ Автоматическая ежедневная загрузка данных через планировщики
- ✅ Агрегация по сессиям (утренняя, основная, вечерняя)
- ✅ Материализованные представления для агрегации объемов

### Фундаментальные данные
- ✅ Загрузка и обновление фундаментальных показателей акций
- ✅ Автоматическое ежедневное обновление (03:00 МСК)
- ✅ Батчинг по 100 активов для оптимизации производительности
- ✅ Принудительное обновление существующих записей

### Дивиденды
- ✅ Загрузка дивидендов по всем акциям за период
- ✅ Автоматическая ежедневная загрузка (00:50 МСК)
- ✅ Поиск дивидендов по FIGI
- ✅ Фильтрация по датам выплаты
- ✅ Статистика по дивидендам

### API и интеграция
- ✅ RESTful API с JSON
- ✅ Асинхронная обработка больших объемов данных
- ✅ Параллельная обработка через пулы потоков
- ✅ Обработка ошибок и валидация
- ✅ Кэширование для повышения производительности
- ✅ Управление кэшем через REST API
- ✅ Детальное логирование всех операций в system_logs
- ✅ Отслеживание статуса асинхронных операций через taskId

## 🏗️ Архитектура

### Основные компоненты

#### Контроллеры (REST API)
- **InstrumentsController** - управление инструментами (акции, фьючерсы, индикативы)
- **CandlesMinuteController** - минутные свечи
- **CandlesDailyController** - дневные свечи
- **CandlesInstrumentController** - свечи конкретных инструментов с расширенной статистикой
- **MainSessionPricesController** - цены основной сессии
- **MorningSessionController** - цены утренней сессии
- **EveningSessionController** - цены вечерней сессии
- **LastTradesController** - обезличенные сделки
- **DividendController** - дивиденды
- **AssetFundamentalsController** - фундаментальные показатели
- **VolumeAggregationController** - агрегация объемов
- **CacheController** - управление кэшем
- **SystemController** - системная информация и мониторинг
- **StatusController** - отслеживание статуса асинхронных операций
- **TradingController** - торговые расписания и статусы
- **RateLimitController** - управление лимитами API

#### Сервисы (Бизнес-логика)
- **InstrumentService** - работа с инструментами
- **CachedInstrumentService** - кэширование инструментов
- **MinuteCandleService** - обработка минутных свечей с параллельной загрузкой
- **DailyCandleService** - обработка дневных свечей с параллельной загрузкой
- **MainSessionPriceService** - цены основной сессии
- **MorningSessionService** - цены утренней сессии
- **LastTradesService** - обезличенные сделки
- **DividendService** - дивиденды
- **AssetFundamentalService** - фундаментальные показатели
- **TInvestService** - фасад для Tinkoff Invest API

#### Планировщики (Автоматические задачи)
- **CandleSchedulerService** - ежедневная загрузка свечей (01:10 МСК)
- **MorningSessionScheduler** - загрузка цен утренней сессии (01:50, 02:01, 07:01, 09:01, 10:01 МСК)
- **EveningSessionSchedulerService** - загрузка цен вечерней сессии (01:40 МСК)
- **ClosePriceSchedulerService** - загрузка цен закрытия (01:00 МСК)
- **LastTradesService** - загрузка обезличенных сделок (03:00 МСК)
- **InstrumentPreloadSchedulerService** - предзагрузка инструментов (00:45 МСК)
- **AssetFundamentalsSchedulerService** - обновление фундаментальных показателей (03:00 МСК)
- **DividendSchedulerService** - загрузка дивидендов (00:50 МСК)
- **VolumeAggregationSchedulerService** - обновление агрегации объемов (02:00 МСК)

### Технологический стек
- **Spring Boot 3.5.4** - основной фреймворк
- **Spring Data JPA** - работа с БД
- **PostgreSQL** - основная БД
- **Tinkoff Invest API (gRPC)** - внешний источник данных
- **Spring Cache** - кэширование инструментов
- **Spring Scheduler** - автоматические задачи
- **Docker** - контейнеризация
- **Maven** - управление зависимостями
- **Java 21** - язык программирования

### Особенности архитектуры
- **Асинхронная обработка** - все POST методы используют параллельную обработку через пулы потоков
- **Кэширование** - автоматический прогрев кэша инструментов при запуске
- **Логирование** - детальное логирование всех операций в system_logs
- **Мониторинг** - отслеживание статуса операций через taskId
- **Транзакционность** - все операции с БД выполняются в транзакциях
- **Обработка ошибок** - комплексная обработка ошибок с graceful degradation
